PVGames permitted-use record
=============================

The following relevant terms are quoted from the local PVGames `Read Me.docx`
supplied with the source packs used as environmental reference material:

- “You absolutely may edit these resources for your project.”
- “You can use these resources in any commercial or non-commercial project that
  you see fit, you just cannot resell or distribute the resources freely, either
  as they are or edited versions. You can use them in any game-making software.”

Project policy: provenance and source handling
----------------------------------------------

The following are Sea Bomber project requirements, not additional PVGames
license terms:

- Retain the originating source pack and transformation in
  `painted-scenery-sources.json` for every derived output.
- Commit only original, transformed scenery swatches; never source archives or
  raw source objects.
- Use these outputs only for scenery and terrain painting.

The recorded Task 5 outputs are repainted 256x256 material swatches. They
retain no complete source building or arch.
